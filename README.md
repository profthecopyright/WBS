# World Bridge Services

The newspaper-style website for World Bridge Services, prepared as a standard
Next.js project for Replit.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Import into Replit

1. In Replit, choose **Create App** and **Import from GitHub**.
2. Select this repository.
3. Replit will use the included `.replit` configuration and Node.js 22.
4. Use **Publish** in Replit when the preview is ready.

The site currently uses external Tally forms and public weather data, so no
database or private environment variables are required.
